# राष्ट्रीय जनादेश प्रमोशनल काउंसिल — वेबसाइट

Next.js 15, React 19, Tailwind CSS, Prisma, MySQL। सार्वजनिक सामग्री व पाठ्यक्रम डेटाबेस से लोड होती है; प्रशासन पैनल REST API के माध्यम से प्रबंधन।

## आवश्यकताएँ

- Node.js 20+
- MySQL 8+ (या संगत)

## स्थापना

1. `.env.example` को `.env` में कॉपी करें और `DATABASE_URL`, `JWT_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` भरें।

2. निर्भरताएँ व Prisma क्लाइंट:

```bash
npm install
npx prisma db push
npm run db:seed
```

3. विकास सर्वर:

```bash
npm run dev
```

- सार्वजनिक साइट: [http://localhost:3000](http://localhost:3000)
- प्रशासक लॉगिन: [http://localhost:3000/admin/login](http://localhost:3000/admin/login)  
  (सीड `ADMIN_EMAIL` / `ADMIN_PASSWORD` env से प्रशासक बनाता है। `ADMIN_PASSWORD` न हो तो नया प्रशासक एक बार का यादृच्छिक पासवर्ड पाता है जो टर्मिनल में छपता है; मौजूदा प्रशासक का पासवर्ड नहीं बदला जाता।)

## पर्यावरण चर

| चर | विवरण |
|-----|--------|
| `DATABASE_URL` | MySQL कनेक्शन स्ट्रिंग |
| `JWT_SECRET` | प्रशासक सत्र हस्ताक्षर। उत्पादन में **अनिवार्य**, कम से कम 32 अक्षर (उदा. `openssl rand -base64 48`)। न होने पर प्रशासक लॉगिन बंद रहता है। |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | सीड / `admin:password` द्वारा सेट प्रशासक (पासवर्ड कम से कम 10 अक्षर, `admin123` जैसे आम पासवर्ड अस्वीकार) |
| `NEXT_PUBLIC_SITE_URL` | कैनोनिकल URL (SEO, मेटाडेटा) |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | WhatsApp (फ्लोट + लिंक); देश कोड सहित, उदा. `918005909134`. खाली होने पर यही डिफ़ॉल्ट। |

## परियोजना संरचना (संक्षेप)

- `src/app` — पेज व App Router
- `src/app/api/public/*` — सार्वजनिक API (सामग्री, संपर्क, न्यूज़लेटर)
- `src/app/api/admin/*` — प्रशासक API (कुकी + JWT)
- `src/components/sections/*` — मुख्य पृष्ठ खंड
- `src/components/admin/*` — प्रशासन UI
- `prisma/schema.prisma` — MySQL स्कीमा
- `prisma/seed.ts` — प्रारंभिक हिंदी सामग्री व नमूना डेटा
- `public/uploads/` — अपलोड की गई छवियाँ

## उत्पादन बिल्ड

```bash
npm run build
npm start
```

MySQL माइग्रेशन के लिए `prisma migrate` उपयोग करें; विकास हेतु `db push` पर्याप्त है।

## उपयोगी कमांड

| कमांड | क्या करता है |
|-------|--------------|
| `npm run db:sync-team` | `prisma/team-data.ts` के जो टीम सदस्य डेटाबेस में नहीं हैं, केवल उन्हें जोड़ता है। बाकी कुछ नहीं बदलता। `-- --update` से सूची वाले मौजूदा सदस्य भी अपडेट होते हैं। |
| `ADMIN_PASSWORD='...' npm run admin:password` | केवल प्रशासक पासवर्ड सेट/रीसेट करता है। |
| `npm run db:seed` | पूरी प्रारंभिक सामग्री लिखता है। **ध्यान दें:** यह सामग्री खंड, पाठ्यक्रम व सूची वाले टीम सदस्यों को सीड के पाठ से बदल देता है — लाइव साइट पर प्रशासन पैनल में किए बदलाव मिट सकते हैं। |

## भाषा (हिंदी / English)

सामग्री हिंदी में है; अंग्रेज़ी Google Translate विजेट से बनती है। नए आगंतुकों के लिए अंग्रेज़ी डिफ़ॉल्ट है। चुनाव `localStorage` (`site-language`) व `googtrans` कुकी में रहता है। अंग्रेज़ी पर जाने पर पेज रीलोड नहीं होता; हिंदी पर लौटने पर एक बार रीलोड होता है। साइट कभी अपने-आप रीलोड नहीं करती।

## सुरक्षा नोट्स

- उत्पादन में मज़बूत `JWT_SECRET` (32+ अक्षर) ज़रूरी है; प्रशासक पासवर्ड प्रशासन पैनल के “पासवर्ड बदलें” पेज से बदलें।
- गलत लॉगिन प्रयास सीमित हैं: एक IP से 8 और एक खाते पर 25 प्रयास प्रति 15 मिनट।
- HTTPS के पीछे होस्ट करें ताकि `httpOnly` कुकी सुरक्षित रहे।
